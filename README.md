# Films

Movie recommendation system using collaborative filtering and content-based approaches.

## Techniques

- Collaborative filtering (user-user, item-item)
- Content-based recommendations (genre, director, actors)
- Matrix factorization (SVD)
- Viewing pattern analysis
- Genre preference modeling

## Tech Stack

- Python
- pandas / NumPy
- scikit-learn
- Surprise (recommendation library)
- Jupyter Notebooks
